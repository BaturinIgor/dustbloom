# DUSTBLOOM pixel style guide

The main visual idea: a grey-lilac wasteland that the player paints alive.
Every action should visibly add colour to the world.

## Grid and scale

- Tiles are **16×16 px**. Characters and scarecrows fit in 16×24 or 24×32.
- On screen a pixel is shown as a whole number of points (×3 on the farm, 48 pt per tile).
  Never scale by fractions, and always draw with nearest-neighbour filtering
  (`SKTexture.filteringMode = .nearest`, SwiftUI `.interpolation(.none)`).
- Light comes from the **top-left**. Every sprite has a 1 px dark outline `#2B1D16`.

## Palette

| Role | Colours |
| --- | --- |
| Outline | `#2B1D16` |
| Wasteland (dust) | `#4F4959` `#5F5869` `#716A7B` `#857E8E` `#9C95A3` `#B8B1BB` |
| Living soil | `#2F1C13` `#452A1C` `#5C3A26` `#774D32` `#91623F` |
| Greens | `#1C4227` `#2A6331` `#3F8A37` `#69B443` `#A9DE63` |
| Gold, wheat | `#7D4F10` `#B97F1A` `#E8B443` `#FFE08A` `#FFF4C8` |
| Ember (pumpkin) | `#6E2810` `#A8461A` `#DD6F26` `#FF9D43` `#FFCF8A` |
| Moon (rare, magic) | `#1B4253` `#2B7383` `#55B9B8` `#9FEAD9` `#E9FFF6` |
| UI parchment | `#F4E6C4` `#E2CC9A`, ink `#3A2A20`, accent gold `#E8B443` |

Rules:
- Warm saturated colours belong only to things the player made alive.
  The wasteland stays cool and muted, so the farm always pops.
- Moon teal and crimson are reserved for rarity, mutations and events.
- Rarity is never shown by colour alone: frame shape changes too (colour-blind players).
- These colours are a hypothesis. Icon and screenshot variants get A/B tested in the App Store.

## Animation

- Crops: 4 stages (seed, sprout, growing, ripe), sway in the wind with a per-tile delay,
  squash-and-stretch "pop" on every stage change, sparkles when ripe.
- Harvest: the crop jumps out, coins fly up toward the counter, the gain floats away,
  a medium haptic tap.
- Errors: the tile shakes and a warning haptic plays. No pop-up dialogs for small mistakes.
- UI: buttons spring, numbers roll instead of jumping.

## Interface

- The farm is the main screen. Systems stay hidden until the player needs them.
- Portrait only. Important buttons live in the bottom third, within thumb reach.
- Parchment panels with a 3 pt dark outline, one gold accent per screen.

## Where the art comes from

All sprites are generated by `art/generate_sprites.py` from this palette, so they can be
regenerated and tweaked in code. `art/preview.png` shows a farm mockup.
